## 페어 고민 (PR body 핵심 발췌)

- `maxLength` props를 받아 입력 길이를 제한하려 했는데, input의`type="number"`에서는 `maxLength`가 동작하지 않는 문제가 있었습니다.
- 두 제약 중 `maxLength`를 선택하고 `type="text"`로 변경한 뒤, 숫자만 입력되도록 제한 로직을 걸었습니다.
- 동일한 상태는 동시에 변하는 값들만 공유해야한다고 생각했기 때문에 카드 번호처럼 비슷한 역할을 하는 input이 여러 개일 때 처음엔 `cardNumber1` `cardNumber2`... 처럼 state를 따로 만들었습니다.
- 하지만 배열 하나로 묶어서 관리하면 훨씬 깔끔하다는 걸 배웠습니다.
- 컴포넌트는 재사용성과 의존도가 낮은게 핵심이라고 생각을 합니다.
