- 도메인 로직이 섞여있는 `Payments`가 UI만을 담당하는 컴포넌트들을 합성하여 구현했습니다.
- 상태를 어디 저장해야될 지에 대해 페어와 많은 이야기를 나눴습니다.

- 상태를 페이먼츠에서 모든 값을 들고있고, 카드 프리뷰에서 실시간으로 값을 연동해줘야 하기 떄문에 카드 번호와 유효기간을 제어컴포넌트로 뒀습니다.
