## 페어 고민 (PR body 핵심 발췌)

- 컴포넌트에서 UI와 도메인을 분리하자.
- 결론적으로 `Input`, `InputField`는 카드 도메인을 모르는 순수 UI 컴포넌트로 두고 `CardNumberInputField`, `CardValidityPeriodInputField`, `CardCVCInputField`에서 각 입력 도메인의 상태와 검증 로직을 결합했습니다.
- 카드 번호 상태를 하나로 관리할지, input마다 따로 관리할지 고민했습니다.
- 그래서 카드 번호를 하나의 상태로 관리하되 배열을 사용해서 각 input의 값을 나누어 관리하는 방식을 선택했습니다.
- 에러 상태를 페이지까지 끌어올리기보다는 각 입력 필드 컴포넌트 내부에서 관리하도록 했습니다.
