# 8기 페이먼츠 1단계 — 반복 안티패턴 요약 (Phase 2 산출물 자리표시자)

## 사용 방식
- Phase 1B 완료 후, _drafts/pr-analysis/pr-*.md 25개를 종합 스캔하여 채운다
- 빈도 ≥ 3건인 패턴만 정식 카드 후보. 2건 이하는 "비주류" 섹션에 메모만
- 기존 q01~q08과의 매핑을 같이 적어 카드 자리잡기 결정

## 컬럼 정의
- **태그**: codex 노트의 [tag] 형식 그대로
- **빈도**: 해당 태그가 달린 PR 개수
- **PR 목록**: 빈도순으로 PR 번호 나열
- **공통 코드 형태**: 한 문장 묘사
- **공통 리뷰 피드백**: 리뷰어들이 이 패턴에 대해 보낸 코멘트 패턴
- **q 매핑**: 가장 가까운 기존 고민 카드 (없으면 "신규")
