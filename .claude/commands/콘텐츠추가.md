# 콘텐츠 추가 도우미

이 저장소에 새로운 미션, 단계, 또는 카드를 추가하는 대화형 프로세스입니다.

## 시작

사용자에게 아래 선택지를 물어보세요:

> **어떤 작업을 하시겠습니까?**
> - A) 기존 미션의 기존 단계에 **카드 추가**
> - B) 기존 미션에 **새 단계 생성**
> - C) **새 미션 생성**

---

## C. 새 미션 생성

1. 미션 이름을 물어보세요 (예: "영화리뷰", "자동차경주")
2. 폴더명을 물어보세요 (예: `movie-review`, `racingcar`) — 영문 케밥케이스 권장
3. 아래 파일들을 생성하세요:
   - `content/{mission}/` 디렉토리
   - `content/{mission}/_meta.json`:
     ```json
     {
       "index": "{미션이름} 미션 홈"
     }
     ```
   - `content/{mission}/index.mdx`:
     ```mdx
     ---
     title: '{미션이름} 미션 PR 아카이브'
     ---

     # {미션이름} 미션 PR 아카이브

     크루의 PR에서 가장 많이 나온 고민과 리뷰어의 피드백을 정리했습니다.

     ---

     ## 단계 선택

     (아직 단계가 없습니다. 단계를 추가해주세요.)
     ```
4. `content/_meta.json`에 새 미션 항목을 추가하세요
5. `content/index.mdx`의 미션 선택 목록에 새 미션 링크를 추가하세요
6. 사용자에게 물어보세요: **"이어서 단계를 추가하시겠습니까?"** → "예"이면 B 흐름으로 이동

---

## B. 새 단계 생성

1. `content/` 하위의 미션 디렉토리를 Glob으로 탐색하여 목록을 보여주세요
2. 사용자에게 미션을 선택하게 하세요
3. 단계 번호/폴더명을 물어보세요 (예: `step1`, `step2`)
4. 사이드바에 표시할 단계 이름을 물어보세요 (예: "1단계 FAQ 카드")
5. 아래 파일들을 생성하세요:
   - `content/{mission}/{step}/` 디렉토리
   - `content/{mission}/{step}/_meta.json`:
     ```json
     {
       "index": "{단계이름} 홈"
     }
     ```
   - `content/{mission}/{step}/index.mdx`:
     ```mdx
     ---
     title: '{단계이름}'
     ---

     # {단계이름}

     (카드를 추가해주세요.)
     ```
6. `content/{mission}/_meta.json`에 새 단계 항목을 추가하세요
7. `content/{mission}/index.mdx`의 단계 선택 목록에 새 단계 링크를 추가하세요
8. 사용자에게 물어보세요: **"이어서 카드를 추가하시겠습니까?"** → "예"이면 A 흐름으로 이동

---

## A. 카드 추가

### A-1. 미션/단계 선택

1. `content/` 하위의 미션 디렉토리를 Glob으로 탐색하여 목록을 보여주세요
2. 사용자에게 미션을 선택하게 하세요
3. 선택한 미션 내 단계 디렉토리를 보여주세요
4. 사용자에게 단계를 선택하게 하세요

### A-2. 카드 섹션 선택

사용자에게 이 카드에 포함할 섹션을 물어보세요:

> **이 카드에 포함할 섹션을 선택해주세요:**
> - ✅ 크루의 질문/고민 (기본 포함)
> - ✅ AS-IS 코드 (기본 포함)
> - ☐ 토론 질문
> - ☐ 리뷰어 피드백
> - ✅ 탐색 미션 (기본 포함)

### A-3. 내용 수집

사용자에게 물어보세요:

> **PR 링크가 있으시면 입력해주세요 (없으면 엔터):**

#### PR 링크가 있는 경우

1. PR 링크에서 owner, repo, PR번호를 파싱하세요
2. `gh api repos/{owner}/{repo}/pulls/{number}` 로 PR 기본 정보(제목, 작성자)를 조회하세요
3. `gh api repos/{owner}/{repo}/pulls/{number}/comments` 로 리뷰 코멘트를 조회하세요
4. `gh api repos/{owner}/{repo}/pulls/{number}/reviews` 로 리뷰를 조회하세요
5. 수집된 정보로 카드 초안을 생성하여 사용자에게 보여주세요
6. 사용자에게 수정 사항을 확인하세요
7. **"PR을 더 추가하시겠습니까?"** → "예"이면 반복

#### PR 링크가 없는 경우 (대화형 인터뷰)

선택된 섹션에 따라 순서대로 물어보세요:

1. **카드 제목**을 입력해주세요 (예: "Q1. 캡슐화 — private과 getter")
2. **파일명 ID**를 입력해주세요 (예: `q01-capsule`) — 영문 케밥케이스
3. **크루의 질문/고민**을 입력해주세요 (크루 이름, PR 번호, 질문 내용)
4. (토론 질문 선택 시) **토론 질문**을 입력해주세요
5. **AS-IS 코드**를 입력해주세요 (언어, 파일명, 코드)
6. (리뷰어 피드백 선택 시) **리뷰어의 피드백**을 입력해주세요
7. **탐색 미션**을 입력해주세요 (PR 링크, 찾아볼 것)

### A-4. MDX 파일 생성

수집된 내용을 아래 템플릿에 맞춰 MDX 파일을 생성하세요.

```mdx
---
title: '{카드 제목}'
---

import { Reveal } from '../../../components/Reveal'

# {카드 제목}

{토론 질문 + 리뷰어 피드백 포함 시에만 아래 읽기 가이드 추가}
> **이렇게 읽어보세요:** 크루의 고민 → 토론 질문을 먼저 읽고 → AS-IS 코드를 직접 분석 → 리뷰어의 피드백으로 관점 확인 → 탐색 미션에서 PR 깊이 파기

## 크루의 질문/고민

> "{질문 내용}" — {크루 이름}, [PR #{번호}]({PR 링크})

{토론 질문 섹션 — 선택 시에만}
### 이 코드를 보면서 이야기해봅시다

- "{질문1}"
- "{질문2}"

## AS-IS 코드

> 출처: [PR #{번호} — {크루 이름}]({PR 링크}) · [해당 파일]({파일 링크})

```{언어}
// {파일명}
{코드}
```

{리뷰어 피드백 섹션 — 선택 시에만}
## 리뷰어의 피드백

> "{피드백 내용}" — PR #{번호} ([링크]({PR 링크}))

---

<Reveal>

## 탐색 미션

### PR #{번호} — {크루 이름}
[PR 링크]({PR 링크})

**찾아볼 것:** "{탐색 과제}"

</Reveal>
```

### A-5. _meta.json 업데이트

1. `content/{mission}/{step}/_meta.json`을 읽어서 새 카드 항목을 추가하세요
2. 파일명 ID를 key로, 사이드바 표시 이름을 value로 추가하세요

### A-6. 완료

생성된 파일 경로와 로컬 URL을 안내하세요:

> **카드가 생성되었습니다!**
> - 파일: `content/{mission}/{step}/{id}.mdx`
> - URL: `/{mission}/{step}/{id}`
> - `npm run dev`로 확인해보세요
