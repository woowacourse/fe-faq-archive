# 페이먼츠 미션 PR 아카이브

크루의 PR과 페어 활동에서 가장 많이 나온 고민, 리뷰어 피드백, 그리고 React 공식문서가 같은 자리에서 무엇을 말하는지를 정리했습니다.

페이먼츠는 React 미션입니다. 그래서 이 아카이브는 로또·영화 리뷰와 한 가지 형태가 다릅니다 — 각 카드에 **공식문서 단서**가 함께 들어갑니다. *입력*과 *비교*가 한 자리에서 닫힙니다.

---

## 단계 선택

### [1단계 — FAQ 카드](/react-payments/step1)

8기 크루가 1단계 페어 진행 중에 직접 적어 보낸 고민들을 카드로 정리했습니다.

- **state를 어디 두고 어떻게 구조화할까** — 가장 많은 고민
- **input 컴포넌트와 검증 책임은 어디까지 끌어올릴까**
- **도메인 규칙(카드 브랜드 식별)은 어디서 알고 있어야 하나**
- 각 카드 = 크루의 질문 + AS-IS 코드 + **공식문서 단서** + 탐색 미션(선배 PR)

---

> 각 카드 하단의 **탐색 미션 열기** 는 코치 안내 후 열어보세요.
