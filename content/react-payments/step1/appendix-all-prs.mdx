# 부록 — 페이먼츠 1단계 PR 전체 인덱스

3~7기 react-payments 1단계 PR을 *모두* 정리한 인덱스입니다. 카드(Q1~Q6)에 강조된 대표 PR 외에도 같은 주제를 다른 결로 다룬 PR이 많습니다.

자기 가설에 가까운 PR을 *추가로* 찾아 들어갈 수 있도록, 각 PR마다 *주요 매핑된 주제*와 *한 줄 키워드*를 적었습니다.
