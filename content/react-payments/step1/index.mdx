# 1단계 FAQ 카드

8기 크루가 페이먼츠 1단계 페어 진행 중에 직접 적어 보낸 고민을 정리했습니다. 여러 페어에서 반복된 고민을 중심으로, 이 미션에서 함께 짚어볼 학습 포인트를 묶었습니다.

> 12쌍 페어의 고민 원본과 그것이 8장 카드로 어떻게 묶였는지는 [8기 페어 고민 → 8장 카드 매핑](/react-payments/step1/crew-pain-points)에서 볼 수 있습니다.
