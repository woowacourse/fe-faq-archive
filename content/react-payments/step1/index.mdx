# 1단계 FAQ 카드

8기 크루가 페이먼츠 1단계 페어 진행 중에 직접 적어 보낸 고민을 정리했습니다. 같은 고민이 6~7개 페어에서 동시에 나왔다는 사실 자체가 *이 미션의 학습 자리*가 어디인지 가리킵니다.

> 12쌍 페어의 고민 원본과 그것이 6장 카드로 어떻게 묶였는지는 [8기 페어 고민 → 6장 카드 매핑](/react-payments/step1/crew-pain-points)에서 한 자리에서 볼 수 있습니다.

---
