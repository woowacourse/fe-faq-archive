# 8기 페이먼츠 1단계에서 본 안티패턴 6선

[Q1~Q8 카드](./q01-state-location)가 *고민*을 다뤘다면, 이 섹션은 **실제로 작성된 코드 안에서 8기 페어들이 반복하고 있는 패턴**을 기록한다.

분석 대상은 8기 1단계 PR 25건 (#497~#524, 중복 재제출 제외). 각 패턴은 **3건 이상에서 동일하게 발견된 신호**만 카드로 추렸다.

> 🔍 **이 섹션의 사용법**
>
> "내가 같은 함정에 빠진 건 아닐까?" — 자기 PR을 다시 열고 각 안티패턴 카드의 *AS-IS 코드*와 비교해본다. 비슷한 형태가 보이면 그 카드의 *리뷰어 피드백*을 읽고 자기 코드를 다시 본다.

## 안티패턴이 모이는 한 가지 단어

위 5개 카드의 공통점은 **"같이 변하지 않는 것을 묶었거나, 묶어야 할 것을 흩뜨렸다"** 이다.

- anti-01 — 4칸의 *에러*는 각자인데, 한 변수로 묶었다
- anti-02 — *식별 규칙*이 여러 prefix인데, 하나만 적었다
- anti-04 — *카드 번호*에서 *브랜드*가 파생되는데, 별도로 묶었다
- anti-05 — *고정 길이*인 정보를 가변 배열로 다뤘다

이 관점은 [Q2 — state 구조 카드](./q02-state-shape)에서 인용한 React 공식문서 5원칙과 같다. 차이는 *고민의 단어*에서 *코드의 단어*로 옮겨진다는 점이다.

> "함께 바뀌나요?" — anti-01, anti-04
> "데이터 형태가 정확한가요?" — anti-02, anti-03, anti-05
