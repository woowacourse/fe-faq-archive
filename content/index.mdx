# 로또 미션 선배 PR 아카이브

선배 크루의 PR에서 가장 많이 나온 고민과 리뷰어의 피드백을 정리했습니다.

---

## 단계 선택

### [1단계 — FAQ 카드](/step1)

선배 크루 116명의 PR에서 가장 많이 나온 **11가지 고민**을 카드로 정리했습니다.

- 객체 설계, 테스트, 코드 다듬기, 구조 잡기
- 각 카드마다 선배 크루의 질문 + AS-IS 코드 + 탐색 미션

### [2단계 — 선배 PR 카드](/step2)

2단계에서 UI를 붙이면서 생기는 고민들을 선배 PR에서 찾아봅니다.

- **A그룹 (도메인을 지킨다)**: Model/View 분리, 의존 방향, 도메인 로직 위치
- **B그룹 (테스트를 확장한다)**: UI 테스트 작성, 테스트 분리, 테스트 전략

---

> 각 카드 하단의 **탐색 미션 열기** 는 코치 안내 후 열어보세요.
