# 우테코 FE 미션 아카이브

우아한테크코스 프론트엔드 미션에서 크루의 PR 고민과 리뷰어 피드백을 교육용 카드로 정리한 사이트입니다.

## 시작하기

```bash
npm install
npm run dev
```

## 콘텐츠 추가하기

Claude Code에서 `/콘텐츠추가` 명령으로 콘텐츠를 추가할 수 있습니다.

- 새 미션 생성, 새 단계 생성, 기존 단계에 카드 추가 모두 지원
- PR 링크를 입력하면 리뷰 코멘트를 자동 수집하여 초안 생성
- 대화형 인터뷰로 직접 내용을 입력할 수도 있습니다

## 배포

```bash
npm run build
```
